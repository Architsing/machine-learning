# Machine Learning – Life Expectancy Prediction 
 
## 📌 Project Overview 
 
This project focuses on analyzing health, economic, and demographic data 
and predicting Life Expectancy using Linear Regression. 
 
The project includes Exploratory Data Analysis (EDA), data preparation, 
feature encoding, model training, prediction, and model deployment 
using Streamlit. 
 
## 📊 Dataset 
 
The dataset contains country-level health, economic, and demographic 
information along with Life Expectancy. 
 
## 🔍 EDA 
 
Performed Exploratory Data Analysis to: 
 
- Understand the dataset 
- Analyze relationships between variables 
- Identify patterns and trends 
- Analyze correlations between features 
- Prepare the data for Machine Learning 
 
## 🤖 Machine Learning 
 
A Linear Regression model was used to predict Life Expectancy. 
 
The project includes: 
 
- Data preprocessing 
- Country encoding using LabelEncoder 
- Feature preparation 
- Model training 
- Prediction 
- Model evaluation 
 
## 🌐 Model Deployment 
 
The trained Machine Learning model was integrated into a Streamlit 
web application. 
 
Users can enter the required feature values and receive a predicted 
Life Expectancy. 
 
## 🛠️ Technologies Used 
 
- Python 
- Pandas 
- NumPy 
- Matplotlib 
- Scikit-learn 
- Joblib 
- Streamlit 
- Google Colab 
 
## 📁 Files
