# Machine Learning – Startup Profit Prediction

## 📌 Project Overview

This project focuses on analyzing startup data and predicting Profit using Multiple Linear Regression.

The project includes Exploratory Data Analysis (EDA), data visualization, data preparation, model training, prediction, and error analysis.

## 📊 Dataset

The dataset contains information about 50 startups and their corresponding Profit.

## 🔍 EDA

Performed Exploratory Data Analysis to:

- Understand the dataset
- Analyze relationships between variables
- Visualize patterns and trends
- Analyze correlations between features

## 🤖 Machine Learning

A Multiple Linear Regression model was used to predict Profit.

The dataset was divided into:

- **Training set** – used to train the model
- **Testing set** – used to evaluate the model

## 📈 Prediction & Error Analysis

The model was used to predict Profit on the test data.

The **actual Profit** was compared with the **predicted Profit**, and the prediction error was analyzed.
